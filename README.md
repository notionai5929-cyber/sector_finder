# sector_finder

어떤 상황에서 어떤 섹터(ETF)를 매매하는 것이 유리한지 분석하기 위한 프로젝트. 미국(미장)과 한국(국장) ETF를 각각 분석한다.

## 구성

```
sector_finder/
├── fetch_sector_data.py   # ETF 주가 데이터 수집 (yfinance)
├── fetch_macro_data.py    # 미국 매크로 지표 수집 (FRED), 국면·근사 발표일 계산
├── analysis.py            # 기간별 상승률 순위, 시차 교차상관(스피어만) 계산
├── macro.py               # 매크로 발표일 기준 구간 수익률, 국면별·4국면·전환 통계
├── app.py                 # 웹 화면 (Flask, localhost:5000)
├── templates/index.html   # 웹 화면 템플릿 (_macro.html = 매크로 탭)
├── tests/                 # pytest 테스트 (python -m pytest)
├── docs/superpowers/      # 매크로 탭 설계 문서와 구현 계획
└── data/
    ├── us/                # 미장
    │   ├── etf_list.csv   # ETF 목록 (그룹, 분류, 표시이름, Yahoo 심볼, 설명, 데이터 기간, 정제 내역)
    │   ├── adj_close.csv  # 전체 ETF 일별 수정종가 (열 = 표시이름, 정제 후)
    │   └── raw/{표시이름}.csv  # ETF별 일별 OHLC, 수정종가, 거래량 (받은 그대로)
    ├── kr/                # 국장 (구성 동일)
    └── macro/
        ├── macro.csv      # 지표별 기준월, 값, 국면 판단 값, 국면, 근사 발표일
        └── raw/{FRED 시리즈}.csv  # FRED에서 받은 그대로
```

## 설치 및 실행

```bash
pip install yfinance pandas flask requests pytest

python fetch_sector_data.py        # 데이터 수집/갱신 (미장 + 국장)
python fetch_sector_data.py kr     # 국장만 (us = 미장만)
python fetch_macro_data.py         # 매크로 데이터 수집/갱신
python app.py                      # 웹 서버 실행 → http://localhost:5000
python -m pytest                   # 테스트
```

## 웹에 배포하기 (Render 무료)

다른 사람이 주소로 접속해 입력값을 바꿔가며 볼 수 있게 하려면 Render(https://render.com)에 배포한다. 배포 설정은 `render.yaml`, 패키지 목록은 `requirements.txt`에 있다.

1. https://render.com 에 GitHub 계정으로 가입한다.
2. Dashboard → **New → Blueprint** → 이 저장소(`sector_finder`)를 고른다. (비공개 저장소면 Render에 GitHub 접근 권한을 준다.)
3. `render.yaml`을 읽어 서비스 `sector-finder`가 만들어지면 **Apply**. 빌드가 끝나면 `https://sector-finder-xxxx.onrender.com` 같은 주소가 생긴다.
4. 이후 `main`에 푸시하면 자동으로 다시 배포된다.

무료 등급의 특징
- 15분간 접속이 없으면 잠들고, 다음 첫 접속은 깨어나는 데 30초~1분 걸린다.
- CPU가 PC보다 훨씬 느려서, 기본 설정(2000년~, 5일) 페이지는 PC(약 3초)보다 오래 걸린다. 시작일을 늦추면 빨라진다.
- 웹에서 `데이터 갱신`을 누르면 그 서버에만 저장되고, 재배포·재시작 때 저장소에 커밋된 데이터로 돌아간다. 데이터를 오래 유지하려면 PC에서 갱신한 뒤 커밋·푸시한다.
- 주소를 아는 사람은 누구나 `데이터 갱신`을 누를 수 있다(동시에 한 번만 실행됨).

## 데이터 수집 (`fetch_sector_data.py`)

- yfinance로 상장일부터 전체 일별 데이터를 받는다 (`auto_adjust=False`라 종가와 수정종가가 모두 저장됨).
- 데이터 기간이 기준(미장 20년, 국장 15년) 미만이면 에러로 중단한다.
- 장 마감 전(미장 16:00 ET, 국장 16:00 KST)에 실행하면 당일 데이터는 장중 값이므로 제외한다.
- 매번 **전체 기간을 새로 받는다**. 배당·분할이 생기면 과거 수정종가도 다시 계산되므로, 새 날짜만 덧붙이면 값이 어긋나기 때문이다.
- 모든 종목을 먼저 받은 뒤 한꺼번에 저장한다. 중간에 실패하면 기존 파일이 그대로 유지된다.

### 데이터 정제 (`adj_close.csv`에만 적용, `raw/`는 받은 그대로)

Yahoo 데이터의 오류를 아래 규칙으로 정제하고, 내역을 `etf_list.csv`의 `cleaning` 열에 남긴다.

1. **긴 공백**: 30일 넘게 데이터가 없는 구간이 있으면 그 이전 데이터를 버린다. (국장 2007-02 ~ 2009-04 공백)
2. **잘못 찍힌 값**: 직전 60거래일 변동성의 15배 넘게(최소 5%) 튀었다가 다음 날 ±1% 안으로 돌아오면 전일 가격으로 대체한다. (국채3년 2010-02-09 +14% 1건)
   - 처음에는 "8% 넘게 튀고 되돌아옴"으로 잡았지만, 2020-03 폭락·반등이나 2026년 국장 급등락처럼 **실제 움직임**까지 걸렸다(네이버 시세로 실제임을 확인). 그래서 변동성 대비 기준으로 바꿨다.
3. **빠진 날**: 다른 종목은 거래됐는데 그 종목만 빠진 날은 최대 5일까지 직전 가격으로 채운다.

참고: 2026-07-31 KODEX200 +24% 같은 큰 움직임은 네이버 시세와 일치하는 실제 값이라 그대로 둔다.

### 데이터 갱신 방법

1. **웹 화면의 `데이터 갱신` 버튼** (권장): 지금 보고 있는 시장(미장 또는 국장)의 데이터를 새로 받아 저장하고, 서버를 다시 켜지 않아도 바로 반영된다(약 15초). 보던 조회 조건은 유지된다.
2. 터미널에서 `python fetch_sector_data.py [us|kr]`: 실행 중인 웹 서버에는 반영되지 않으므로 서버를 다시 켜야 한다.

웹 화면 상단에 데이터 최종일이 표시되고, 해당 시장의 최신 거래일보다 오래되면 "갱신 필요" 경고가 나온다(주말만 고려하고 공휴일은 고려하지 않으므로, 공휴일 다음 날에는 경고가 잘못 뜰 수 있다).

## 기간별 상승률 순위 (웹 화면)

`python app.py` 실행 후 http://localhost:5000 접속.

화면 맨 위의 **미장 / 국장** 버튼으로 시장을 전환한다. 전환하면 순위표, 상관표, 조건부 표, 매수/매도추천이 모두 그 시장의 데이터로 다시 만들어지고, 입력한 조회 조건은 유지된다.

| 입력 | 기본값 | 설명 |
|---|---|---|
| 시장 | 미장 | 미장 / 국장 버튼 |
| 검색 시작일 | 2000-01-01 | 이 날짜 이후 첫 거래일부터 구간 시작 |
| 단위일수 n | 5 | 한 구간의 **거래일** 수 (5 ≈ 1주) |

- 열 = 구간(시작일/종료일), 행 = 순위, 셀 = `티커 (상승률%)`
- 셀 색: 초록 = 상승, 빨강 = 하락 (진할수록 변동 큼). 마우스를 올리면 분류와 ETF 이름 표시
- **상승률 = 구간 마지막 날 수정종가 / 구간 직전 거래일 수정종가 − 1** (구간 사이에 빠지는 날이 없음)
- 해당 구간에 상장 전인 ETF는 순위에서 제외 (미장 예: 2000년 초에는 11개, 2006-02 이후 24개 전체 / 국장: 2011-10 이후 21개, 2023-06 이후 25개 전체)
- 마지막 구간이 n일보다 짧으면 흐리게 표시
- **칸을 클릭하면 같은 ETF의 모든 칸이 노란색으로 표시**되어 시간에 따른 순위 변화를 추적할 수 있다. 같은 ETF를 다시 클릭하면 해제.

## 분석 기준 옵션 (상관/조건부 표에 적용)

| 입력 | 기본값 | 설명 |
|---|---|---|
| 상관/조건부 분석 기준 | 벤치마크 초과수익 | `초과수익` = 각 ETF 구간 상승률 − 벤치마크 구간 상승률 (미장 SPY, 국장 KODEX200. 벤치마크 열/행 제외), `원수익률` = 그대로 |
| 조건부: 순위 상위 % | 20 | 조건부 표에서 "순위표 상위"로 볼 범위 (1~50) |

순위표는 기준 옵션과 관계없이 항상 원수익률로 표시한다. 같은 구간 안에서 벤치마크를 빼도 순위는 바뀌지 않기 때문이다.

## 섹터 후행성 평가 ①: 시차 교차상관 (웹 화면, 순위표 아래)

"가로 ETF가 오른 뒤 세로 ETF가 얼마나 잘 오르는가"를 보기 위한 표 3개.

| 표 | 시간 딜레이 | 기본값(n=5) |
|---|---|---|
| 1 | 단위일수 × 1 | 5거래일 |
| 2 | 단위일수 × 2 | 10거래일 |
| 3 | 단위일수 × 3 | 15거래일 |

- 축: 가로(열) = 선행 ETF, 세로(행) = 후행 ETF (24 × 24)
- 칸 값: 가로 ETF의 t구간 상승률과 세로 ETF의 t+k구간 상승률의 **스피어만 상관계수**
- 구간은 순위표와 동일하게 n거래일씩 겹치지 않게 나누며, n일보다 짧은 마지막 구간은 제외
- 두 ETF 모두 데이터가 있는 구간만 사용 (표본 10개 미만이면 `-`)
- 색: 파랑 = 양의 상관(가로 상승 후 세로도 상승 경향), 빨강 = 음의 상관
- 굵은 글씨 + `*` = p < 0.05, 흐린 글씨 = 유의하지 않음, 테두리 = 대각선(자기상관: 모멘텀/반전)
- 칸에 마우스를 올리면 ρ, p-value, 표본 수(N) 표시
- p-value는 SciPy 없이 정규근사(t = ρ·√((N−2)/(1−ρ²)))로 계산. 표본이 수백 개 이상이면 오차가 작다.
- 같은 (시작일, n, 기준) 조합의 계산 결과는 서버 메모리에 캐시된다.

## 섹터 후행성 평가 ②: 조건부 성과 (웹 화면, 상관표 아래)

"순위표에서 가로 ETF가 **상위권에 든 뒤** 세로 ETF가 어땠는가"를 직접 보는 표 3개 (딜레이는 상관표와 같이 단위일수 × 1, 2, 3).

- 조건: 순위표의 t구간에서 가로 ETF가 상위 X%(기본 20%) 순위에 듦
  - 그 구간에 데이터가 있는 ETF끼리 원수익률로 순위를 매김 (순위표와 동일, 벤치마크 포함)
  - 상위 개수 = 반올림(그 구간 ETF 수 × X%), 최소 1개 → 24개면 5위까지, 11개(2000년 초)면 2위까지
- 칸 윗줄: 그때 세로 ETF의 t+k구간 **평균 상승률(%)**, 아랫줄: **상승확률(%) · 표본 수(N)**
- 표 머리의 **상위 진입** 행: 가로 ETF가 순위 상위 X%에 든 횟수
- 표본이 10개 미만인 칸은 **회색**(신뢰하기 어려움, 유의성 표시 안 함). `-` = 상위에 든 적이 없어 표본 없음
  - 예: 2000년~, n=20, 상위 10%(24개 중 2위 이내)에서 SPY·IVE는 0회, DVY 2회, LQD 3회. SPY·IVE 같은 분산형 ETF는 섹터 평균에 가까워 극단적인 순위에 잘 들지 않는다.
- 색: 평소(가로 ETF 데이터가 있는 전체 구간의 평균) 대비 차이. 파랑 = 평소보다 좋음, 빨강 = 나쁨
- 굵은 글씨 + `*` = |t| > 1.96, t = (조건부 평균 − 평소 평균) / (조건부 표준편차 / √N)
- 칸에 마우스를 올리면 조건부/평소 평균, 조건부/평소 상승확률, t, N 표시
- 순위는 t 시점에 이미 알 수 있는 정보이므로 사후적 기준이 아니다. (단, 거래비용은 반영하지 않음)

### 현재 구간 매수/매도추천 (조건부 표 아래)

순위표(표1)의 **마지막 열을 현재 진행 중인 구간**으로 보고, 각 조건부 표에 그 구간을 예측하는 열을 노란 테두리로 표시한다.

| 조건부 표 | 노란 테두리 열 = 순위표의 이 구간에서 상위 X%에 든 ETF |
|---|---|
| 표5 (딜레이 × 1) | 마지막 − 1 열 |
| 표6 (딜레이 × 2) | 마지막 − 2 열 |
| 표7 (딜레이 × 3) | 마지막 − 3 열 |

- 각 표 아래 **매수추천 / 매도추천**: 노란 테두리 열의 칸 중 아래 조건을 모두 만족하는 세로(후행) ETF
  - 매수: 표본 N ≥ 10, t > 기준(기본 1.96), 조건부 평균 > 0, 상승확률 > 50%
  - 매도: 표본 N ≥ 10, t < −기준, 조건부 평균 < 0, 상승확률 < 50% (초과수익 기준이면 "벤치마크 대비 부진 = 비중 축소 후보")
  - 기준 |t|는 **1.96 고정**이다(`app.py`의 `T_MIN`). 아래 "t 값과 기준 1.96"의 검증 결과에 따른 값이다.
  - 예: `VNQ ← XLY 상위 후 10거래일 SPY 대비 상승률 +0.3% (평소 -0.0%), 상승확률 53% (평소 49%), t=2.28, N=253`
- 조건을 만족하는 칸이 없으면 "없음"으로 표시한다.
- 서로 비슷하게 움직이는 ETF(예: 채권 SHY·IEF·TLT·TIP·LQD)는 한 가지 효과가 여러 줄로 나타날 수 있다.
- 데이터가 오래되면 "현재 구간"도 과거가 되므로, 사용 전에 `python fetch_sector_data.py`로 갱신한다.
- 마지막 열이 n일을 다 채운 구간이어도 진행 중인 구간으로 간주한다.
- 과거 통계상 경향일 뿐이고 다중비교로 우연한 신호가 섞일 수 있으며, 거래비용은 반영하지 않는다.

### t 값과 기준 1.96

**t = (조건부 평균 − 평소 평균) / (조건부 표준편차 / √N)**

- 분자: 선행 ETF가 상위에 든 뒤의 평균이 평소보다 얼마나 다른지
- 분모(표준오차): 표본 N개의 평균이 우연만으로 흔들리는 정도. N이 클수록 작아진다.
- t = 2는 "차이가 우연에 의한 흔들림의 2배"라는 뜻이다. 실제로 아무 효과가 없을 때 |t| > 1.96이 나올 확률은 약 5%(양측, 정규근사)다.
- 같은 차이라도 N이 많거나 변동이 작은 ETF일수록 t가 커진다.
- 한계: 평소 평균에 조건부 구간도 포함되어 있어 약간 보수적이고, 칸이 수백 개라 1.96을 넘는 칸 중 일부는 우연이다.

**기준 검증 (학습 2000~2013 / 검증 2013~2026, SPY 초과수익, 상위 20%, 딜레이 ×1~3 합산)**

학습 기간에 |t|가 기준을 넘은 칸이 검증 기간에도 같은 방향이었는지 확인했다.

| \|t\| 기준 | n=5: 학습 신호 수 | n=5: 검증 같은 방향 | n=5: 검증 평균 효과 | n=20: 학습 신호 수 | n=20: 검증 같은 방향 |
|---|---|---|---|---|---|
| 0 (전부) | 1584 | 53% | +0.02%p | 1488 | 50% |
| 1.00 | 451 | 61% | +0.06%p | 380 | 44% |
| 1.65 | 131 | 65% | +0.11%p | 99 | 38% |
| **1.96** | 57 | **68%** | **+0.13%p** | 40 | **28%** |
| 2.58 | 8 | 75% | +0.08%p | 8 | 38% |
| 3.00 | 3 | 67% | +0.09%p | 5 | 20% |

- n=5(주 단위)에서는 기준을 높일수록 검증에서도 맞는 비율이 올라가고, 1.96 부근에서 신호 수와 효과의 균형이 가장 좋다. **1.96은 과한 설정이 아니다.** 다만 효과가 주당 +0.13%p 수준이라 거래비용을 빼면 남는 게 거의 없다.
- 2.58 이상은 신호가 너무 적어(8개 이하) 판단하기 어렵다.
- n=20(월 단위)에서는 학습 기간의 신호가 검증 기간에 오히려 **반대로** 움직였다. 기준값을 바꿔서 해결되는 문제가 아니라 관계 자체가 시기에 따라 바뀐 것이다.

## 매크로 분석 탭

순위표(표1) 아래의 **[단순 시간 영향성] [매크로 분석]** 탭으로 전환한다. 단순 시간 영향성 탭은 위의 상관표·조건부 표·추천이고, 매크로 분석 탭은 미국 매크로 국면별로 ETF 성과를 본다. 선택한 탭만 계산하며, 탭은 주소(`tab=time|macro`)에 남아 새로고침·데이터 갱신 후에도 유지된다.

목적: **지금 매크로 국면에서 과거에 어떤 섹터가 좋았는지**, **국면이 바뀔 때 어떤 섹터로 갈아탈지** 찾는다. 미장/국장 모두 같은 미국 매크로를 쓴다.

### 매크로 데이터 (`fetch_macro_data.py` → `data/macro/`)

| 지표 | FRED 시리즈 | 국면 | 근사 발표일 |
|---|---|---|---|
| 기준금리 | FEDFUNDS (월평균) | 인상 / 동결 / 인하 (전월 대비 ±0.1%p) | 해당 월 말일 |
| CPI | CPIAUCSL | YoY가 3개월 전보다 상승 / 하락 | 다음 달 20일 (주말이면 다음 월요일) |
| PCE | PCEPI | YoY가 3개월 전보다 상승 / 하락 | 다음 달 마지막 평일 |
| 제조업 경기 | GACDFSA066MSFRBPHI (필라델피아 연은, ISM PMI 대체) | 3개월 전보다 개선 / 악화 | 해당 월 셋째 목요일 |
| 장단기 금리차 | T10Y2Y (10년−2년, 월말 값) | 3개월 전보다 확대 / 축소 | 해당 월 말일 |

- ISM 제조업 PMI는 2016년 FRED에서 빠진 유료 데이터라 필라델피아 연은 제조업지수로 대체했다.
- **CPI 근사 발표일을 실제보다 늦은 쪽(20일)으로 잡은 이유**: 구간은 "발표일 종가 → 다음 발표일 종가"라서, 발표 당일의 큰 변동은 직전 구간에 들어가고 새 구간은 발표를 확인한 뒤부터 시작한다. 근사일이 실제 발표보다 **빠르면** 아직 나오지 않은 CPI로 국면을 정하고 발표일 변동까지 그 국면의 성과로 계산하게 된다(처음 쓴 13일 규칙은 2024년 11번 중 2번이 실제보다 1~2일 빨랐다). 근사일이 **늦으면** 새 구간이 며칠 늦게 시작할 뿐 미래 정보는 섞이지 않는다.
- 발표일이 아직 오지 않은 값(진행 중인 달의 금리차 등)은 저장하지 않는다.
- 웹의 `데이터 갱신` 버튼이 ETF와 매크로를 함께 갱신한다. FRED 접속이 실패하면 기존 매크로를 유지하고 ETF 갱신 결과는 그대로 반영한다.

### 계산

- **구간** = 지표 발표일의 종가 → 다음 발표일의 종가. 미장은 발표일(휴장이면 다음 거래일) 종가, 국장은 미국 발표가 한국 장 마감 뒤라 **발표 다음 거래일** 종가부터.
- 그 구간의 국면은 **발표일에 나온 값**으로 판단한다(발표 전 정보를 쓰지 않음, 테스트로 검사).
- 단위일수 n과 순위 상위 %는 쓰지 않고, 시장·검색 시작일·기준(원수익률/벤치마크 초과수익)은 따른다.
- **4국면** = 경기(제조업 방향) × 물가(CPI 방향): 회복(개선·하락), 과열(개선·상승), 스태그플레이션(악화·상승), 침체(악화·하락). CPI 발표일 기준이며, 그 시점까지 발표된 최신 제조업 국면을 쓴다.
- **국면 전환** = 직전 구간이 현재 4국면이었다가 다른 국면으로 바뀐 직후 1개월(다음 CPI 발표까지)의 성과.
- t = (국면 평균 − 전체 구간 평균) / (국면 표준편차 / √N). 전환표의 "전체"도 전체 구간 평균이다.

### 화면

1. **현재 국면**: 지표별 최신 값, 근사 발표일, 현재 국면, 최근 12회 국면 변화(현재와 같은 국면은 노란색)
2. **지표별 국면표 5개**: 행 = ETF, 열 = 국면. 칸 = 다음 발표일까지 평균 상승률, 상승확률 · N. 현재 국면 열은 노란 테두리
3. **경기 × 물가 4국면 표**: 구성 동일
4. **국면 전환표**: 열 = "현재 국면 → 다른 국면"
5. 각 표 아래 추천
   - 지표·4국면 표: "현재 국면에서 좋았던/나빴던 ETF" (N≥10, |t|>1.96, 평균과 상승확률 방향 일치)
   - 전환표: "국면이 ○○로 바뀌면 갈아탈 후보 / 피할 ETF" (전환 5회 이상, 같은 기준). 전환 표본이 수십 회라 참고용

- 각 표 아래 **국면 해석** 메모: 국면마다 일반적으로 알려진 의미와 유리하다고 여겨지는 섹터를 적었다(현재 국면은 노란 배경). 교과서적 일반론이므로, 이 데이터에서 실제로 그랬는지는 표로 확인한다. 메모 원문은 `fetch_macro_data.py`의 `GUIDES`, `macro.py`의 `REGIME4_GUIDE`.

### 장단기 금리차 역전 검증: "역전되면 항상 큰 하락장이 온다"?

1976년 이후 10년−2년 금리차가 0 아래로 내려간 7번(1년 넘게 정상이었다가 다시 역전된 경우를 새 역전으로 셈)에 대해, 역전 후 48개월 동안의 S&P 500(^GSPC)을 확인했다.

| 역전 시작 | 48개월 내 최대 낙폭 (고점→저점) | 역전 시점 대비 최저 | 12개월 후 | 다음 경기침체(NBER) |
|---|---|---|---|---|
| 1978-08 | −27% (1980-11→1982-08) | −12% | +3% | 1980-02 (17개월 후) |
| 1988-12 | −20% (1990-07→1990-10) | −1% | +28% | 1990-08 (19개월 후) |
| 1998-05 | −37% (2000-03→2001-09) | −12% | +19% | 2001-04 (34개월 후) |
| 2000-02 | −49% (2000-03→2002-10) | −45% | −4% | 2001-04 (14개월 후) |
| 2005-12 | −57% (2007-10→2009-03) | −46% | +14% | 2008-01 (24개월 후) |
| 2019-08 | −34% (2020-02→2020-03) | −22% | +21% | 2020-03 (6개월 후) |
| 2022-04 | −22% (2022-04→2022-10) | −21% | −10% | 36개월 내 없음 |

- **7번 모두 4년 안에 약 20% 이상 하락이 있었다.** "역전 뒤 큰 하락"은 지금까지는 맞았다.
- 하지만 **아무 달에 시작해도 4년 안에 20% 이상 하락이 올 확률이 49%**다(1975년 이후). 역전이 확률을 높이는 것은 맞지만, 표본이 7번뿐이라 "항상"이라고 단정하기는 어렵다.
- **시점이 들쭉날쭉하다.** 고점은 역전 후 1~27개월 뒤였고, 7번 중 5번은 역전 후 1년간 주가가 올랐다(+3%~+28%). 4번은 하락의 바닥이 역전 시점 가격보다 1~12%만 낮았다. 역전되자마자 팔았다면 상승을 놓치고 오히려 손해였던 경우가 많다.
- **원인이 다른 경우도 섞여 있다.** 2019년 역전 뒤 하락은 코로나 충격이고, 2022년 역전은 이미 진행 중이던 하락장 한가운데서 나왔으며 그 뒤 침체 없이 상승했다.
- 금리차 역전은 마지막으로 2024-09-05에 풀렸고, 2026-11 현재 금리차는 +0.3%p 안팎의 정상 상태다.
- 재현: `data/macro/raw/T10Y2Y.csv`, FRED `USREC`(경기침체 기간), yfinance `^GSPC`.

### 한계

- 발표일은 규칙으로 근사한 값이라 실제와 며칠 차이가 날 수 있다(공휴일 미고려). CPI는 늦은 쪽(20일)으로 잡아 새 구간 시작이 실제보다 며칠 늦다.
- 지표는 최신 수정치를 쓰므로 발표 당시 값과 다를 수 있다(특히 PCE).
- 국면 전환 표본이 작다(2000년 이후 4국면 전환은 수십 회).
- **추천이 구간 경계에 민감하다.** CPI 근사 발표일을 13일에서 20일로 옮기자(2026-11-21) 매크로 탭의 추천 상당수가 바뀌었다(예: 미장 스태그플레이션의 VNQ/VOX가 사라지고, 전환표에 VNQ·XLU·DVY가 새로 나옴). 신호의 상당 부분이 우연일 수 있으므로, 여러 표에서 같은 방향으로 반복되는 ETF만 참고하는 것이 좋다.
- 현재 국면 열에서 유의한 ETF가 없는 경우가 많다(2026-11 기준 미장은 지표별 표에서 거의 "없음"). 국면 하나만으로 섹터 성과를 가르는 힘이 약하다는 뜻이기도 하다.

## 검토 결과 및 개선 포인트 (미장 기준)

2000-01-01 시작, n = 5, 딜레이 5거래일 기준으로 실제 계산한 수치.

1. **시장 공통 요인 제거 → 구현 완료 (SPY 초과수익 옵션, 기본값)**
   원수익률 기준 576칸 중 280칸이 p < 0.05인데, SPY 초과수익(ETF 수익률 − SPY 수익률)으로 계산하면 83칸으로 줄어든다. 대각선(자기상관)도 전부 음수다.
   즉 현재 표의 상당 부분은 "시장 전체가 한 주 오르면 다음 주에 조금 되돌린다"는 단기 반전을 반영한 것이고, 어떤 섹터를 고를지에 대한 정보는 아니다. → SPY 초과수익 기준 계산 옵션 추가.
2. **다중비교 보정**
   576번 검정하면 우연만으로도 약 29칸이 p < 0.05가 된다. Bonferroni 보정(p < 0.05/576)을 통과하는 칸은 30개뿐이다. → 보정을 통과한 칸을 별도 표시(Bonferroni 또는 FDR).
3. **시기 안정성 검증**
   기간을 2000~2013 / 2013~2026으로 나눠 상관행렬을 비교하면 일치도가 0.49(초과수익 기준 0.19)다. 한 시기의 선행 관계가 다음 시기에 잘 유지되지 않는다. → 종료일 입력 추가 또는 기간 분할/롤링 비교.
4. **조건부 분석 추가 → 구현 완료 (조건부 성과 표)**
   상관계수는 크기가 작고(|ρ| ≤ 0.14) 하락 구간까지 섞여 있다. "가로 ETF가 크게 오른 뒤"라는 질문에는
   "가로 ETF가 상위 20%로 오른 구간 다음, 세로 ETF의 평균 수익률과 상승 확률" 같은 조건부 표가 더 직접적이고 매매 판단에 바로 쓸 수 있다.
5. **구간 시작점에 따른 결과 변동**
   시작일을 하루만 바꿔도 구간 경계가 달라져 결과가 바뀐다. → 시작점을 0 ~ n−1일씩 밀어 계산한 결과를 평균.
6. **속도**
   표 6개를 포함한 기본 설정에서 처음 열 때 약 5.5초 걸린다(상관/조건부 표는 캐시되어 다시 열면 빨라짐).

### SPY 초과수익 기준 결과 (2000~, n = 5, 상위 20%)

| 딜레이 | 상관 p<0.05 | 상관 Bonferroni 통과 | 조건부 \|t\|>1.96 | 우연 기대치 |
|---|---|---|---|---|
| 5일 | 83 / 529 | 6 | 45 / 529 | 약 26 |
| 10일 | 32 / 529 | 0 | 13 / 529 | 약 26 |
| 15일 | 46 / 529 | 0 | 15 / 529 | 약 26 |

- 조건부 표에서 유의한 칸은 5일 딜레이에서 45개로 우연 기대치(약 26)보다 조금 많고, 10·15일에서는 그보다 적다. **"A가 상위권에 들면 B가 다음에 오른다"는 관계는 짧은 딜레이에서만 약하게 보인다.**
- Bonferroni를 통과한 6칸은 모두 채권(LQD, SHY 후행 ← 채권 선행)이다. 채권의 SPY 초과수익은 사실상 −SPY에 가까워서, 여전히 시장의 단기 반전이 드러난 것으로 보인다.
