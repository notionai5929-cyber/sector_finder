# 매크로 분석 탭 설계

작성일: 2026-11-21

## 목적

지금까지의 분석(순위표 아래 상관표·조건부 표·추천)은 "직전 구간에 무엇이 올랐는가"라는 **시간 흐름**만 본다.
매크로 분석 탭은 미국 매크로 지표를 기준으로 다음 두 질문에 답한다.

1. **지금 매크로 국면**에서 과거에 어떤 섹터(ETF)가 좋았고 나빴는가
2. **매크로 국면이 바뀔 때** 어떤 섹터로 갈아타야 하는가

## 목표 / 하지 않을 것

목표
- 순위표(표1) 아래를 **[단순 시간 영향성] [매크로 분석]** 두 탭으로 나눈다. 지금의 표2~7과 추천은 첫 탭으로 그대로 옮긴다.
- 매크로 데이터 5종을 `data/macro/`에 따로 저장하고, 데이터 갱신 버튼으로 함께 갱신한다.
- 미장/국장 버튼으로 바꾸면 매크로 탭도 그 시장 ETF로 다시 계산한다(매크로는 둘 다 미국 지표).

하지 않을 것
- 매크로 지표 자체의 예측(다음 CPI가 오를지 등)
- 한국 매크로 지표
- 유료 데이터(ISM PMI 등)
- 과거 시점의 발표 당시 값(수정 전 값) 복원. 최신 수정치를 쓴다(한계로 명시).

실패로 볼 것
- 발표 전에는 알 수 없던 매크로 값으로 그 이전 수익률을 설명하는 것(미래 정보 사용). 반드시 **발표일 이후** 수익률만 쓴다.

## 제약

- 데이터 출처: FRED 무료 CSV (`https://fred.stlouisfed.org/graph/fredgraph.csv?id=<series>`). `requests`로 정상 수신 확인(0.3초). 표준 `urllib`에 브라우저 User-Agent를 넣으면 응답이 멈췄으므로 `requests`를 쓴다.
- ISM 제조업 PMI는 2016년 FRED에서 빠진 유료 데이터라 **필라델피아 연은 제조업지수**로 대체한다.
- FRED 무료 CSV에는 발표일이 없다. 발표일은 지표별 규칙으로 근사한다(아래). 실제 발표일과 며칠 차이가 날 수 있다.
- 표본: 월 단위라 미장 2000년~ 약 320개월, 국장 2009년~ 약 200개월(테마 ETF는 더 적음). 4국면·전환 분석은 표본이 작아진다.

## 접근 방식 (검토한 안)

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 지표별 방향 | 지표마다 상승/하락 국면별 섹터 성과 | 이해 쉬움, 표본 넉넉 | 지표 조합이 안 보임 |
| B. 조합 국면 | 경기 × 물가 4국면(회복·과열·스태그플레이션·침체) | 국면 전환을 읽기 좋음 | 국면별 표본 감소, 발표일 다른 지표를 맞춰야 함 |
| **C. A + B (선택)** | 지표별 표 + 4국면 표 + 국면 전환표 | "지금 국면에 좋았던 섹터"는 A로, "갈아탈 섹터"는 B의 전환표로 답함 | 표가 많아짐 |

사용자가 **C**를 선택했다.

## 사용자가 정한 것

- 매크로 분석은 단위일수 n을 쓰지 않는다. **매크로 발표일 기준 월 단위**로, "이번 발표일 ~ 다음 발표일" 구간의 ETF 상승률로 비교한다.
- 매크로 지표: 미국 금리, CPI, PCE, 제조업 PMI, 장단기 금리차.
- 분석 방식: C (지표별 + 4국면 + 전환).

## 설계

### 1. 데이터 (`fetch_macro_data.py` → `data/macro/`)

| 지표 | FRED 시리즈 | 원 주기 | 국면 판단 값 | 발표일 근사 규칙 |
|---|---|---|---|---|
| 기준금리 | FEDFUNDS (월평균) | 월 | 전월 대비 변화 | 해당 월 말일 (월평균은 월말에 확정) |
| CPI | CPIAUCSL | 월 | 전년 대비 상승률(YoY) | 다음 달 20일 (주말이면 다음 영업일). 2026-11-21 변경: 13일은 실제보다 빠른 달이 있어 미래 정보가 섞임 |
| PCE | PCEPI | 월 | 전년 대비 상승률(YoY) | 다음 달 마지막 영업일 |
| 제조업 경기 | GACDFSA066MSFRBPHI (필라델피아 연은) | 월 | 지수 수준 | 해당 월 셋째 목요일 |
| 장단기 금리차 | T10Y2Y (10년−2년) | 일 | 월말 값 | 해당 월 말일 |

저장 파일
- `data/macro/raw/{시리즈}.csv`: FRED에서 받은 그대로
- `data/macro/macro.csv`: 행 = 지표 기준월, 열 = 지표별 값, 국면 판단 값, 근사 발표일

갱신: 웹의 `데이터 갱신` 버튼이 현재 시장 ETF와 매크로를 함께 갱신한다. 터미널은 `python fetch_macro_data.py`.

### 2. 국면 정의

지표별(A)
- 기준금리: **인상 / 동결 / 인하** (전월 대비 +0.1%p 초과 / ±0.1%p 이내 / −0.1%p 미만)
- CPI, PCE: YoY가 **3개월 전보다 상승 / 하락** (월별 등락은 잡음이 커서 3개월 변화로 판단)
- 제조업 경기: 지수가 **3개월 전보다 상승 / 하락**
- 장단기 금리차: **3개월 전보다 확대 / 축소**. 표에 역전(<0) 여부를 함께 표시

조합(B): 경기 × 물가 4국면
- 경기 = 제조업 경기 방향, 물가 = CPI YoY 방향
- 회복(경기↑ 물가↓), 과열(경기↑ 물가↑), 스태그플레이션(경기↓ 물가↑), 침체(경기↓ 물가↓)
- 기준 발표일 = CPI 발표일. 그 시점에 이미 발표된 최신 제조업 지수를 쓴다.

### 3. 구간과 수익률

- 지표마다 자기 발표일로 구간을 나눈다: 구간 k = 발표일 k의 종가 → 발표일 k+1의 종가.
- 발표일이 휴장일이면 다음 거래일 종가를 쓴다. 국장은 한국 시간 기준 다음 거래일(미국 발표가 한국 장 마감 뒤라서).
- 그 구간에 적용되는 국면 = 발표일 k에 발표된 값으로 판단한 국면.
- 기준(원수익률 / 벤치마크 초과수익)은 기존 옵션을 그대로 따른다.
- 검색 시작일 이후 구간만 사용한다. 단위일수 n과 순위 상위 %는 매크로 탭에서 쓰지 않는다.

### 4. 화면 (매크로 분석 탭)

1. **현재 국면 요약**: 지표별 최신 값, 발표일, 현재 국면, 4국면 중 현재 국면. 최근 12개월 국면 변화를 한 줄로 표시.
2. **지표별 국면표 (A) 5개**: 행 = ETF, 열 = 국면(예: CPI 상승 | CPI 하락). 칸 = 다음 발표일까지 평균 상승률, 상승확률, N. 색은 전체 평균 대비 차이, t > 1.96이면 굵게·`*`. **현재 국면 열은 노란 테두리**. 표 아래에 "현재 국면에서 좋았던/나빴던 ETF"(기존 추천과 같은 기준: N≥10, |t|>1.96, 평균과 상승확률 방향 일치).
3. **4국면 표 (B)**: 행 = ETF, 열 = 4국면. 구성은 2와 같고 현재 국면에 노란 테두리, 아래에 좋았던/나빴던 ETF.
4. **국면 전환표 (C)**: 현재 국면에서 다른 3개 국면으로 바뀐 직후 1개월의 ETF 성과. 열 = 전환 방향(예: 과열→스태그플레이션), 칸 = 평균 상승률, 상승확률, 전환 횟수 N. 아래에 "국면이 ○○로 바뀌면 갈아탈 후보". 전환 횟수가 적으므로 N<10이면 회색, 추천은 N≥5에서만 표시하고 "표본 적음"을 명시.

탭 전환: `tab=time|macro` 주소 값으로 유지한다(새로고침·데이터 갱신 후에도 같은 탭). 선택한 탭만 계산해 페이지를 가볍게 한다.

### 5. 한계(화면과 README에 명시)

- 발표일은 규칙으로 근사한 값이다.
- 최신 수정치를 쓰므로, 발표 당시 값과 다를 수 있다(특히 PCE).
- 국면 전환 표본이 작다(2000년 이후 4국면 전환은 수십 번 수준).

## 만드는 사람에게 맡기는 것 (제 판단으로 정한 부분, 승인 시 확정)

- 국면 판단을 "3개월 전 대비"로 한 것, 기준금리 동결 범위 ±0.1%p
- 장단기 금리차를 확대/축소로 나누고 역전 여부는 표시만 한 것 (역전/정상으로 나눌 수도 있음)
- PCE는 헤드라인(PCEPI) 사용 (근원 PCE로 바꿀 수 있음)
- 4국면의 물가 축은 CPI 사용 (PCE로 바꿀 수 있음)
- 발표일 근사 규칙
- 전환표의 관찰 기간 = 전환 직후 1개월
- 파일 구조: `fetch_macro_data.py`, `macro.py`(국면·구간 계산), `templates/index.html`에 탭 추가

## 검증

- 발표일 규칙: 알려진 실제 발표일 몇 개(예: 2024년 CPI 발표일)와 비교해 차이 확인
- 구간 수익률: 임의 구간 하나를 손으로 계산해 일치 확인
- 미래 정보 점검: 각 구간의 국면 판단에 쓴 값의 발표일이 구간 시작일 이전인지 자동 검사
- 미장/국장, 시작일 변경, 데이터 부족 상황에서 화면 생성 확인
