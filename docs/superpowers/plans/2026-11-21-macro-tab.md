# 매크로 분석 탭 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 순위표 아래를 [단순 시간 영향성] / [매크로 분석] 탭으로 나누고, 미국 매크로 5종의 발표일 기준 월 구간으로 국면별·4국면별·국면 전환별 ETF 성과와 추천을 보여준다.

**Architecture:** `fetch_macro_data.py`가 FRED에서 받아 국면과 근사 발표일을 계산해 `data/macro/macro.csv`(long format)에 저장한다. `macro.py`가 시장 가격(`PRICES[market]`)과 발표일로 구간 수익률을 만들고 국면별 통계를 낸다. `app.py`가 `tab` 값에 따라 한쪽 탭만 계산하고 `templates/index.html`이 탭과 표를 그린다.

**Tech Stack:** Python 3.14, pandas, requests, Flask/Jinja, pytest

**Spec:** `docs/superpowers/specs/2026-11-21-macro-tab-design.md`

## Global Constraints

- FRED CSV: `https://fred.stlouisfed.org/graph/fredgraph.csv?id=<series>`, `requests.get(..., timeout=30)` (urllib + 브라우저 UA는 멈춤)
- 시리즈: FEDFUNDS, CPIAUCSL, PCEPI, GACDFSA066MSFRBPHI, T10Y2Y(일별 → 월말 값)
- 국면: 기준금리 인상/동결/인하(전월 대비 ±0.1%p), CPI·PCE YoY / 제조업 지수 / 금리차는 3개월 전 대비 상승·하락
- 4국면: 경기 = 제조업 방향, 물가 = CPI YoY 방향. 회복(↑↓) 과열(↑↑) 스태그플레이션(↓↑) 침체(↓↓). 기준 발표일 = CPI 발표일, 그 시점 이미 발표된 최신 제조업 국면 사용
- 발표일 근사: FEDFUNDS·T10Y2Y = 기준월 말일, CPI = 다음 달 13일(토·일이면 다음 월요일), PCE = 다음 달 마지막 평일, 필라델피아 = 기준월 셋째 목요일
- 구간: 발표일 k의 기준 종가 → 발표일 k+1의 기준 종가. 미장 = 발표일 당일 또는 이후 첫 거래일, 국장 = 발표일 **다음 날 이후** 첫 거래일
- 추천 기준: N≥10, |t|>1.96, 평균과 상승확률 방향 일치 (기존 `MIN_N`, `T_MIN` 재사용). 전환표 추천은 N≥5, "표본 적음" 표시
- 매크로 탭은 단위일수 n, 순위 상위 %를 쓰지 않는다. 시장·시작일·기준(원수익률/초과수익)은 따른다.

    v = pd.Series([5.33, 5.33, 5.08, 5.12], index=pd.date_range("2024-08-01", periods=4, freq="MS"))

def test_classify_cpi_uses_yoy_3m_change():

    v = pd.Series([100 * 1.01 ** i for i in range(18)], index=idx)   # 일정한 상승률 → YoY 변화 0

    assert out["signal"].iloc[12:].round(6).nunique() == 1          # YoY 일정
    assert out["state"].iloc[:15].isna().all()                       # YoY 12개월 + 3개월 변화 필요

  - `state_stats(periods: pd.DataFrame, states: list[str]) -> dict[str, dict]` — 국면별 `mean, hit, n, t` (각 `dict[티커, float]`)와 전체 `base_mean, base_hit`. t = (국면 평균 − 전체 평균) / (국면 표준편차/√N)
  - `transition_stats(periods: pd.DataFrame, current: str) -> dict[str, dict]` — 직전 구간 국면 = `current`이고 이번 구간 국면이 다른 국면인 구간만 모아 `"current→next"`별 `mean, hit, n, t`
  - `current_state(releases: pd.DataFrame) -> dict` — 최신 `release_date, state, value`와 최근 12개 국면 목록
